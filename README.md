# DSS ARIMA · Inventarios Metalmecánicos

Aplicación Streamlit del proyecto **Modelo de pronóstico y reposición de inventarios basado en ARIMA para reducir quiebres de stock bajo incertidumbre en empresas comercializadoras de productos metalmecánicos**.

## Base incluida
- 30 SKU
- 12 meses: junio 2025 – mayo 2026
- 360 registros SKU-mes
- Resultados ARIMA precalculados para navegación inmediata

## Despliegue en Streamlit Community Cloud
1. Subir el contenido de esta carpeta a un repositorio GitHub.
2. Entrar a https://share.streamlit.io e iniciar sesión con GitHub.
3. Crear una app existente desde el repositorio.
4. Branch: `main`.
5. Entry point: `app.py`.
6. En Advanced settings seleccionar Python 3.12.
7. Elegir un subdominio disponible y desplegar.

La aplicación no necesita secretos ni servicios externos.
